# CSCI-164-Project-Applied-Machine-Learning-with-scikit-learn
Final Project
This project compares supervised learning models across three datasets using scikit-learn.

**Authors:** Julian Hidalgo,Jose Avila, Mauricio Martinez, Julio Franco

# Datasets
- Heart Disease
- Spotify Yearly Track Metadata (2014–2026)
- Housing Prices

# Models used
- Logistic Regression
- K-Nearest Neighbors
- Decision Tree
- Linear Regression
- KNN Regressor
- Decision Tree Regressor
- Naive Bayes
- Ridge Regression

# Summary 
This project explores baseline models, EDA + preprocessing, Hyperparameter tuning (GridSearchCV), Evaluation + literature comparison and summary report with presentation.
